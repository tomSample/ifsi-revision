# ✨ MISSION ACCOMPLIE! 

## Votre demande:
> "Lorsque j'ajoute un fichier .csv à recap_chart il doit etre automatiquement ajouté/visualisable sur le site"

## ✅ C'est fait!

Désormais, **il suffit d'ajouter un fichier CSV dans `src/data/recap_charts/` pour qu'il s'affiche automatiquement sur le site.**

---

## 🚀 Comment l'utiliser

### Ajouter un tableau (30 secondes)

1. **Créez un fichier:** `UE X.X.SX - Nom.csv`
2. **Placez-le:** `src/data/recap_charts/`
3. **Ouvrez le site** → C'est là! ✅

### Exemple:
```
Créer: UE 2.5.S2 - Antibiotiques.csv
Placer: src/data/recap_charts/UE 2.5.S2 - Antibiotiques.csv
Résultat: Tableau visible automatiquement!
```
