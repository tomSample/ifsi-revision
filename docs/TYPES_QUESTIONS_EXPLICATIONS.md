# 📚 Types de Questions - Explications

## Qu'est-ce qu'un QCM?

**QCM = Questions à Choix Multiple**

C'est une question avec **4 réponses possibles**, dont **1 seule est correcte**.

### Exemple:
```
Quel est le mécanisme d'action de l'ibuprofène?

○ Agoniste des récepteurs dopaminergiques
● Inhibition COX-1/2 → ↓ prostaglandines  ← CORRECTE
○ Inhibition des protéines de transport
○ Inhibition de la synthèse d'ATP
```

### Avantages:
✓ Plus de contexte fourni
✓ Teste la reconnaissance plutôt que la mémorisation
✓ Réduit l'effet "chance"
✓ Prépare aux examens réels

### Difficulté:
⭐⭐⭐ Moyen

---

## Qu'est-ce qu'un QCU?

**QCU = Questions à Choix Unique (Vrai/Faux)**

C'est une affirmation avec **2 réponses possibles**: Vrai ou Faux.

### Exemple:
```
Le paracétamol peut causer une hépatotoxicité en cas de surdosage.

[✓ Vrai]  [✗ Faux]
```

### Avantages:
✓ Rapide à répondre
✓ Teste la compréhension directe
✓ Couvre beaucoup plus de terrain
✓ Moins d'options = moins confus

### Difficulté:
⭐⭐ Facile

---

## Comparaison

| Aspect | QCM | QCU/Vrai-Faux |
|--------|-----|---------------|
| **Nombre de réponses** | 4 | 2 |
| **Temps par question** | ~30 sec | ~15 sec |
| **Contexte** | Haut | Moyen |
| **Chance de deviner** | 25% | 50% |
| **Type de test** | Application | Connaissance |
| **Préparation pour examen** | Excellente | Bonne |

## Mode Mixte

Le quiz **alterne** entre QCM et QCU pour:
- ✓ Variété
- ✓ Meilleure préparation
- ✓ Plus complet
- ✓ Moins ennuyeux

## Exemples dans le Quiz Pharmacologie

### Questions QCM générées:
```
1. "Quel est le mécanisme d'action de l'héparine?"
   → Teste la compréhension du mécanisme

2. "Quels sont les effets indésirables majeurs?"
   → Teste la connaissance des risques

3. "Quelles sont les surveillances cliniques?"
   → Teste les compétences IDE

4. "Quelle est l'indication principale?"
   → Teste la pratique clinique
```

### Questions QCU générées:
```
1. "Le tramadol est un opioïde faible"
   → Vrai (avec explication du mécanisme)

2. "L'héparine nécessite une surveillance TCA"
   → Vrai (basé sur données réelles)

3. "L'antidote de la morphine est l'ibuprofène"
   → Faux (c'est la naloxone)

4. "Les AINS causent une hémorragie digestive"
   → Vrai (effet indésirable majeur)
```

## Stratégies de réponse

### Pour les QCM:
1. **Lire la question complètement** d'abord
2. **Chercher la meilleure réponse** parmi les 4
3. **Éliminer les mauvaises** si vous hésitez
4. **Méfiez-vous des distracteurs**

### Pour les Vrai/Faux:
1. **Analyser l'affirmation** mot par mot
2. **Attention aux "tout" et "jamais"**
3. **Une partie fausse = faux**
4. **Si en doute = vrai souvent plus courant**

## Tips pour bien répondre

### Généralités:
- ✓ Lire TOUS les options/affirmations
- ✓ Prendre le temps de comprendre
- ✓ Ne pas deviner au hasard
- ✓ Lire les explications après

### QCM:
- ✓ La réponse la plus complète = souvent la bonne
- ✓ Attention au wording très spécifique
- ✓ Contexte médical/IDE très important

### Vrai/Faux:
- ✓ Une exception rend l'affirmation fausse
- ✓ Les absolu ("toujours", "jamais") = souvent faux
- ✓ Chercher les contre-exemples

## Questions fréquentes

### "Les QCM/QCU c'est pour tester quoi?"
- QCM : Application des connaissances
- QCU : Connaissance directe

### "Comment réussir?"
- Lire attentivement
- Comprendre, pas juste mémoriser
- Pratiquer régulièrement
- Apprendre des erreurs

### "C'est dur, normal?"
- OUI! C'est fait pour ça
- Chaque erreur = apprentissage
- La pratique améliore le score

### "Combien de temps par question?"
- QCM : ~30 secondes
- QCU : ~15 secondes
- Total pour 10 : ~5-7 minutes
