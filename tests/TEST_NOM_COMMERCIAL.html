☑️ Checkbox dans l'Interface

Le nouveau checkbox apparaît automatiquement dans le quiz:

  • Localisation: Section "Domaines d'étude" du formulaire de configuration
  • Label: "Identification par nom commercial"

🔧 Données Utilisées

La fonctionnalité utilise les colonnes du fichier pharmaco.csv:
