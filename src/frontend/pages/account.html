📖 Guide d'utilisation - IFSI Révision

🎯 Système de révision espacée

L'application utilise la répétition espacée pour optimiser votre mémorisation :

  • Facile 😊 : Revoir dans ~6 jours
  • Moyen 🤔 : Revoir dans ~3 jours
  • Difficile 😓 : Revoir dans 1 jour

🏷️ Classification collaborative

Classifiez chaque terme selon son importance selon vous :

  • 🔴 Essentiel : Concept fondamental à maîtriser
  • 🟡 Important : Notion clé à connaître
  • 🟢 Complémentaire : Information utile mais secondaire
  • ⚫ Ignorer : Terme non pertinent pour vous

Les votes de chaque utilisateur seront pris en compte pour mettre en avant les termes les plus importants et mieux cibler vos révisions.

📊 Statistiques détaillées

Consultez votre progression :

  • Nombre de termes révisés
  • Taux de réussite par UE
  • Historique des révisions
  • Termes à revoir aujourd'hui

📱 Application PWA

Installez l'app sur votre appareil :

  • Synchronisation automatique
  • Notifications de révision (bientôt)

🔒 Données personnelles

Vos données sont synchronisées en temps réel via Firebase. Vous pouvez :

  • Réinitialiser vos classifications
  • Supprimer votre compte

💡 Astuce : Révisez 10-15 minutes par jour pour des résultats optimaux !
